Recommendations

✓
Use the Batch API

This workflow is a textbook Batch API use case — you're processing files overnight, not in real time. The 50% discount halves your total cost with zero change to output quality. Configure it once in the script and forget it.

✓
Enable Prompt Caching on the System Prompt

Your improvement prompt is identical across every file in a given pass. That's a perfect cache candidate. After the first file, subsequent input costs drop to 10% of standard — stacking on top of the Batch discount to push total spend below $8.

⚠
Limit the Casting Prompt to ~20–25 Files

For titles with no confirmed casting (older classics, books without active adaptations), the model will produce thin or fabricated content. Curate a whitelist of titles with known cast data before running this pass. This also keeps that prompt's cost proportional.

→
Budget Time for Output Review

The bigger cost isn't API spend — it's your time reviewing results. Spot-check at least 20% of files per pass (roughly 16 files). Run one pass at a time and validate before proceeding to the next, especially for the FAQ schema and internal linking passes where errors compound.

Bottom Line

Running all five improvement passes across your full library will cost somewhere between $8 and $27 depending on which optimisations you enable. That's a remarkably low barrier for the volume of structured work involved. The real investment is in prompt quality and output review — get those right and the API spend is trivially small relative to the SEO and content value returned.
