# BooksVersusMovies.com — Project Structure
============================================
Last updated: April 14, 2026

This is the authoritative reference for the current project layout after the transition to a full JSON-first pipeline with greenfield generation.

### Core Architecture Principles
- **JSON is the source of truth** — All review content lives in structured JSON files.
- **LLM never touches HTML** — Only the renderer (`pipeline-render.js`) generates HTML.
- **Separation of concerns** — Prompts, config, data stages, and rendering are isolated.
- **Pipeline is linear and idempotent** — Extract → Generate/Revise → Render → Deploy.

### Directory Overview

#### Root (`/`)
Contains all live, deployed files served by Netlify with pretty URLs.
- `index.html` — Main landing page (generated by `pipeline-browse.js`)
- Individual review pages (`the-godfather.html`, `verity.html`, etc.)
- `auteurs.html`, `about.html`, `welcome.html`
- `sitemap.xml`, `robots.txt`, `package.json`

#### `scripts/`
All executable Node.js code.
- **Core Pipeline Scripts**:
  - `pipeline-generate.js` — Greenfield two-stage generator (Stage 1 + Stage 2)
  - `pipeline-revise.js` — Pass 1, Titles pass, Pass 2
  - `pipeline-render.js` — JSON → final HTML (deterministic)
  - `pipeline-browse.js` — Generates `index.html`
  - `pipeline-extract.js` — Legacy HTML → JSON bootstrap
- **Supporting Scripts**:
  - `validate-json-schema.js`, `logger.js`, `quality-gate.js`
  - `generate-review.js`, `pipeline-auteurs.js`, `sitemap-generate.js`
  - `export-titles.js`, `import-titles.js`, etc.
- `prompts/` — All LLM prompts (greenfield-stage1.txt, greenfield-stage2.txt, pass1-*.txt, etc.)

#### `config/`
- `models.json` + environment variants (`models-dev.json`, `models-test.json`, `models-prod.json`)
- `advice.json`, `auteurs.json`

#### `data/`
**Primary data layer**
- `data/reviews/*.json` → **Canonical source of truth** for all live reviews (162+ files)
- `data/greenfield/`
  - `inputs/` → Minimal input files for new reviews
  - `stage1/` → Factual metadata from Stage 1 (Haiku)
  - `stage2/` → Full editorial review JSON from Stage 2 (Sonnet)
- `data/schemas/` → JSON schema definitions
- `data/reports/gsc/` and `analytics/` → Performance exports
- `extracted_metadata.csv`, `titles-export.csv`, etc.

#### `pipeline/` (Working directories)
- `pipeline/1-extracted/` → Legacy raw extraction (mostly historical now)
- `pipeline/2-revised/` → Final revised JSON ready for rendering (copied from greenfield or revise)
- `pipeline/3-rendered/` → Final HTML output before copying to root

#### `reviews/`
- Mirror/copy of deployed HTML files (some duplication exists due to deployment process)
- `reviews-to-review/` → Quarantine folder for problematic or legacy pages

#### `docs/`
Strategy, documentation, and reference material.
- `completed-tasks.md`, `ROADMAP-TECHNICAL.md`, `ROADMAP-PRODUCT.md`
- `business-strategy.md`, `project-objectives.md`, `pipeline-notes.md`
- `review-schema.md`, `POLICIES.md`, `project-structure.md` (this file)
- Archived advice and consolidated docs

#### `images/`
- Book cover images named exactly after slug (`the-godfather.jpg`, etc.)

#### `logs/`
- Timestamped logs from all pipeline runs

#### `archive/`
- Old scripts, legacy HTML, and superseded files

---

### Current Pipeline Flows

**Greenfield (New Review)**
1. Create minimal JSON → `data/greenfield/inputs/`
2. `pipeline-generate.js` → Stage 1 (facts) → Stage 2 (full content)
3. Output → `pipeline/2-revised/`
4. Titles pass + Pass 2 → `pipeline-render.js`
5. HTML copied to root

**Revision (Existing Review)**
`pipeline-revise.js` → `pipeline-render.js`

**Homepage**
`pipeline-browse.js` reads from `pipeline/2-revised/` → generates `index.html`
