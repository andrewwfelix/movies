BooksVersusMovies.com — Pipeline Action Plan
=============================================

1. Housekeeping
   1.1 Move wild.html to reviews-to-review
   1.2 Update extract-metadata.js to exclude non-review files, treat director as optional
       for series pages, and handle non-standard book years like "800 BC"
   1.3 Re-run extractor to produce a clean baseline metadata.csv in data/

2. Define the content/structure divorce
   2.1 Design the JSON schema that all pipeline operations will read and write —
       one file per review, stored in data/reviews/
   2.2 Write a one-time extraction script that converts existing HTML pages into
       their JSON representations
   2.3 Add the quick-answer CSS component to style.css

3. Build the revision pipeline
   3.1 Write Pass 1 prompt — structural overlay: generates quick-answer block,
       verifies FAQ quality, checks CTA placement
   3.2 Write the Node pipeline script that reads a JSON file, runs Pass 1 via the
       Anthropic API, and writes the result back to JSON
   3.3 Single-page prompt evaluation loop: run Pass 1 on one page, read JSON output,
       judge quality, adjust prompt, repeat before scaling
   3.4 Write Pass 2 prompt — conversion layer: improves CTA wording, adds mid-article
       CTAs after decision moments
   3.5 Extend the pipeline script to run Pass 2 after Pass 1
   3.6 Test on five pages, review output quality manually before running at scale

4. Build the renderer
   4.1 Write a minimal renderer that handles the existing page structure without
       the quick-answer block — enables visual validation during prompt development
   4.2 Extend the renderer to handle the full revised structure including
       quick-answer block and updated CTA placements
   4.3 Validate rendered output against three known-good pages to confirm fidelity
   4.4 Run renderer across all files in data/reviews/ and write output to reviews/

5. Build the greenfield pipeline
   5.1 Design the input data format — the structured fields a new review needs
       before any LLM is involved
   5.2 Write the generation prompt that produces a complete review JSON from
       input data
   5.3 Wire the greenfield prompt into the same renderer from step 4 so new and
       revised pages share one render path

6. Validate and ship
   6.1 Spot-check 10 revised pages against originals for voice, accuracy,
       and structure
   6.2 Confirm affiliate links, YouTube IDs, and related cards are intact
       across all pages
   6.3 Re-run extractor as a final QA pass to confirm no missing fields
       across the full set
   6.4 Deploy and monitor GSC for CTR changes over 4 weeks
