🧠 What we changed (and why)

We just did a structural correction of your content system, not a “bug fix.”

The core problem wasn’t broken scripts — it was multiple competing sources of truth:

JSON review data (data/reviews/*.json)
HTML spotlight pages (hand-written / partially generated)
Repair scripts that tried to “patch” HTML after the fact

That architecture inevitably produces drift, silent failures, and inconsistent recommendations.

🎯 The key insight

HTML should never be repaired. It should be re-rendered from canonical data.

So we moved you from:

❌ Old model (fragile)
HTML → parse → detect issues → patch → hope nothing broke
JSON (separate system) → unrelated logic
repair scripts → heuristic fixes (“a-beautiful-mind” fallback issue)
✅ New model (deterministic)
JSON (source of truth)
   ↓
graph builder (deterministic relationships)
   ↓
renderer (rebuild HTML from scratch)
   ↓
spotlight pages (pure output)

This eliminates:

silent parsing failures
broken slug detection mismatches
duplicate repair logic
inconsistent related-card generation
“fallback spam” replacements
📦 What we changed (file-by-file)
1. scripts/utils/build-related-graph.js (NEW)
Why it exists

This replaces all heuristic matching in repair scripts.

What it does
Reads all data/reviews/*.json
Extracts related[] fields
Normalizes them into a clean adjacency graph
Why this matters

Instead of guessing “best replacement,” we now have:

a deterministic graph of valid relationships

This is the foundation of everything.

2. scripts/utils/render-spotlights.js (NEW — core system)
Why it exists

This replaces ALL:

fix-related-cards-spotlight.js
fix-related-cards.js
any HTML patching logic
What it does
Loads the graph
Finds each spotlight page slug
Rebuilds the entire .related-grid
Writes clean HTML back
Why this matters

We stopped “repairing HTML” and started:

regenerating UI from data

This eliminates drift permanently.

3. scripts/utils/validate-spotlights.js (OPTIONAL / future tool)
Why it exists

Debugging + sanity checks only.

What it would do
Compare spotlight HTML → graph
Report mismatches
Never writes files
Why this matters

You now separate:

rendering (authoritative)
validation (diagnostic only)

This is critical for stability.

4. DEPRECATED (implicitly replaced)
❌ fix-related-cards.js
❌ fix-related-cards-spotlight.js
Why they are now obsolete

They were based on:

heuristic scoring (genreScore)

Why that failed

Because they assumed:

But your system already has the relationships — just not centralized.
